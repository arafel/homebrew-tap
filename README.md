# Arafel Tap

## How do I install these formulae?

`brew install arafel/tap/<formula>`

Or `brew tap arafel/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "arafel/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
